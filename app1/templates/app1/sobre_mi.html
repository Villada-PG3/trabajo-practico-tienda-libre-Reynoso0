Acerca de mí

Soy Mateo y estoy aprendiendo desarrollo web con Django.

Mi camino en programación

Empecé este proyecto como parte de un curso de desarrollo web, con el objetivo de entender cómo funciona una aplicación real de punta a punta: desde el modelo de datos hasta lo que finalmente ve el usuario en el navegador.

Esta tienda es mi espacio de práctica. Cada clase agrego algo nuevo: primero fueron las páginas estáticas, después conecté las vistas con la base de datos usando el ORM de Django, y ahora estoy trabajando en que todo se vea prolijo con Bootstrap.

Por qué Django

Elegí Django porque permite pasar rápido de una idea a algo funcionando: el ORM hace que trabajar con la base de datos sea intuitivo, y el sistema de templates ayuda a mantener el HTML organizado sin repetir código entre páginas.

Próximos pasos

A medida que avance el curso, la idea es sumar más funcionalidades a esta tienda: detalle de cada producto, un carrito de compras, y quizás en algún momento, un sistema de usuarios para poder guardar pedidos.
